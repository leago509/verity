# verity

Verity is an AI-powered meeting intelligence platform designed to transform recorded meetings into structured, actionable insights. It processes audio and video recordings to generate accurate transcriptions, structured meeting minutes, and action items, helping users review discussions and track important decisions more efficiently.

A key feature of Verity is its AI-generated content verification system, which checks generated statements against the original meeting transcript using semantic retrieval and Natural Language Inference (NLI). Each statement is classified as Supported, Partially Supported, or Unsupported, with timestamped transcript evidence to help users verify the accuracy of the generated content.

Developed using React, TypeScript, Python, FastAPI, and open-source AI models, Verity aims to improve meeting documentation, transparency, and accountability by making AI-generated meeting summaries more reliable and traceable.
